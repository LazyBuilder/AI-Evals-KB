# Evals Lab imagery

Six original editorial illustrations were created with the built-in OpenAI image generation tool for this website on November 5, 2026. They are conceptual illustrations, not photographs of actual AI infrastructure or scientific diagrams.

The website uses optimized WebP versions in `assets/images/`. Images are included locally in the GitHub Pages package and are not hotlinked to another website.

The Voice Bot Reality Check website was reviewed as a design reference for the use of hero and section imagery. None of its image assets were copied.

## Prompt set

The full generation prompts are retained in `IMAGE_PROMPTS.json` beside this file in the source project and in the final package.

| File | Role |
| --- | --- |
| hero.webp | Evidence passing through five inspection frames |
| foundation.webp | A curated collection of glass sample tiles |
| definition.webp | A caliper and an illuminated acceptance boundary |
| measurement.webp | An optical bench, prism, and detector plates |
| protection.webp | A glass boundary deflecting particles from a protected core |
| authority.webp | A deliberate inspection checkpoint and release gate |

Each image also has a smaller responsive version with a `-small` suffix.
